# Module 01: Go Fundamentals

Part of [Phase 5: Go for DevOps Automation](../README.md).

Goal: solid Go syntax and core building blocks, always tied to a DevOps use case, before moving into modules/packages, APIs, AWS SDK and beyond.

Each lesson folder contains three files:

- `lesson-N-notes.md` — big picture, detailed notes, analogies
- `lesson-N-recall.md` — short-answer drill with an answer key
- `lesson-N-exercise.md` — hands-on task, what to submit, completion checklist
