# Session 1b · Service Models — IaaS, PaaS, SaaS

## The Question These Models Answer

"How much do I manage myself, and how much does AWS manage for me?"

## The Pizza Analogy

| Model | Pizza equivalent | What you handle | What's handled for you |
|---|---|---|---|
| On-Premises | Made from scratch | Dough, oven, table — everything | Nothing |
| IaaS | Take-and-bake | Your own oven, plates, table | Pre-made pizza (raw infrastructure) |
| PaaS | Delivery | Plates, table | The cooking (it arrives ready) |
| SaaS | Dine at a restaurant | Just show up and eat | Everything |

## Mapped to Real Tools

| Model | AWS examples | Everyday examples |
|---|---|---|
| IaaS | EC2, EBS, VPC | Renting a bare server |
| PaaS | Elastic Beanstalk, RDS | Heroku-style deploy, managed database |
| SaaS | — | Gmail, Zoom, Slack |

## Key Terms

- **IaaS** — Infrastructure as a Service: rent raw compute/storage/network
- **PaaS** — Platform as a Service: rent a ready-to-use runtime/platform
- **SaaS** — Software as a Service: rent a finished application
