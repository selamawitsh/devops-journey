# Session 1a · What Is Cloud Computing?

> Part of my Qiyas Cloud Computing learning log — Session 1 concepts, in my own words.

## The Core Idea

Cloud computing = renting IT resources (servers, storage, databases, networking) over the
internet, and paying only for what you use instead of buying and owning the hardware
yourself.


## Traditional IT vs Cloud

| | Traditional (On-Prem) | Cloud (AWS) |
|---|---|---|
| Servers | Buy physical hardware | Rent on-demand |
| Setup time | Weeks (hardware delivery) | Minutes |
| Cost model | Huge upfront cost (CapEx) | Pay-as-you-go (OpEx) |
| Who manages the datacenter | You | AWS |
| Capacity planning | Guess in advance | Scale up/down instantly |
| Going global | Build datacenters abroad | A few clicks |


## Key Terms

- **CapEx (Capital Expenditure)** — upfront cost, buying an asset outright
- **OpEx (Operating Expenditure)** — ongoing cost, paying for usage over time
- **On-demand** — available immediately, no waiting or procurement process
- **Pay-as-you-go** — billed for actual consumption, not a fixed subscription
