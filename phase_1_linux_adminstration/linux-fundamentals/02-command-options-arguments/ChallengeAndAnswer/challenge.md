# Real-World DevOps Challenge — Command Options and Arguments

## Scenario
A senior DevOps engineer hands you a list of tasks to run on a server.
They only tell you the command name, not the options. You have to figure
out the right options yourself using only the terminal.

---

## Question 1
List all files in `/var/log` showing their sizes in human-readable format
(KB, MB — not raw bytes). What option achieves this?


## Question 2
Show the current date in ISO format. Then show it in the default format.
What is the difference and why would ISO format matter in log files?


## Question 3
List files in `/etc` showing hidden files AND long format AND
human-readable sizes — all in a single command.


## Question 4
You see a teammate run: `ls -lah /var/log`
Break down every part of this command. What does each character do?



## Question 5
Run `date --help` and find one option you did not know about before.
What does it do? Try it.
