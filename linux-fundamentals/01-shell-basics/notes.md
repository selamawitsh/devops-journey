# Shell Basics

## What is the shell?

The shell is Linux's command interpreter. When you log in, a shell starts
and waits for you to type commands. It reads what you type, figures out
what you mean, runs it, shows you the result, then waits again. This loop
never stops until you log out.

The most common shell on Linux is bash (Bourne Again Shell). There are
others like sh, ksh, csh — but bash is what you will use 99% of the time.

## The prompt

The shell shows a prompt to tell you it is ready. It usually looks like:
** username@hostname:~$

The `$` means you are a normal user. If you see `#`, you are root (superuser).

## Logging in and out

- To log out: type `exit` or press `Ctrl+D`
- To log in again: type your username, press Enter, type your password
